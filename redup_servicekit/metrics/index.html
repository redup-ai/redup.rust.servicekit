Prometheus metric registry, bucket constants and EMA store.

Metric names, label names, label ordering and histogram buckets are semantically identical to redup.python.servicekit (redup_servicekit.metrics + MonitorStorage). All metrics carry the inittime label (process start time string), inittime first.

Naming rule: the Python client renders counters with a _total suffix (started -> started_total), while the Rust prometheus crate does not append it. To keep the wire format identical, counter metric names in this crate already include the _total suffix, e.g. started_total, completed_total, stats_tasks_time_spend_total.
