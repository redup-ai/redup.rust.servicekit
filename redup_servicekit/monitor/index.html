Monitoring core: task tracking, statistics and the main ServiceKit.

Semantically identical to redup.python.servicekit.monitoring (MonitorStorage + MonitorServer): stats are accumulated in memory and the Prometheus registry is refreshed lazily on each /metrics request (refresh()), exactly like refresh_registry_for_metrics().
