Tonic gRPC layer collecting per-method metrics.

Analog of aio_grpc_method_wrapper from redup.python.servicekit: per call it increments stats_request{method}, registers a task (started_total), measures duration/response size, on success/failure increments stats_processed{method,status}, on error increments stats_errors{method,type} and observes time full___method__<m> (EMA + stats_hist_time_full), request_size___method__<m> and response_size___method__<m>.

The layer is compatible with tonic::transport::Server::layer: it wraps the service and maps HTTP requests to gRPC service/method names.
