YAML configuration singleton with merge and environment overrides.

Mirrors redup_servicekit.config.ConfigSingleton from redup.python.servicekit: deep merge of additional YAML files or values, environment overrides with ___ (triple underscore) for nesting and __ (double underscore) for spaces in key names, comma-separated env values become lists. Only keys already present in the config are overridden.
